# Azura Travel - Mediterranean Destinations

A responsive, high-end travel destination website built strictly using **pure HTML5 and CSS3** (no JavaScript dependencies or frameworks required).

![Azura Travel Preview](https://images.unsplash.com/photo-1516483638261-f4dbaf036963?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Key Features

1. **Sticky Navigation Bar:**
   - Fixed header with blurred glassmorphism backdrop (`backdrop-filter: blur(16px)`).
   - Brand logo, clear section links, and an instant "Book Now" CTA.
   - Pure CSS mobile hamburger drawer (using the accessible `<input type="checkbox">` pattern).

2. **Hero Section:**
   - Full-width scenic tourist banner featuring a high-res coastal destination.
   - Elegant typography pairing (`Playfair Display` + `Plus Jakarta Sans`).
   - Bold headline, subtext, dual call-to-action buttons, and social-proof stats bar.

3. **Places to Visit:**
   - Fully responsive CSS Grid of attraction cards (Santorini, Zakynthos, Amalfi Coast, Balos Lagoon, Cinque Terre, Capri Island).
   - Category tags, ratings, prices, location icons, and hover zoom effects.

4. **Travel Packages:**
   - 3-tier pricing comparison: **Essential Explorer**, **Wanderer Explorer (Most Popular)**, and **Azure Signature VIP**.
   - Clear included/excluded feature lists and direct booking action buttons.

5. **Local Activities:**
   - Showcase of authentic experiences (Coastal Trekking, Catamaran Sunset Sailing, Snorkeling & Scuba, Vineyard & Olive Tasting, Sea Kayak Arch Expedition, Artisan Pottery & Cooking).
   - Custom SVG icons, badges, durations, and difficulty levels.

6. **Booking Section:**
   - Two-column layout with booking assurances, refund guarantees, and contact hotline.
   - Fully styled, accessible HTML form with package selection, travel dates, guest count, contact fields, and notes.

7. **Footer:**
   - Newsletter subscription callout.
   - Brand story, navigation links, popular destinations, contact details with office hours, and social media links.
   - Responsive copyright & legal footer.

## 📱 Responsive Breakpoints

- **Desktop (> 1024px):** Multi-column CSS Grid and Flexbox layouts.
- **Tablet (768px - 1024px):** Adaptive 2-column grids and centered pricing stacks.
- **Mobile (< 768px):** Pure CSS slide-down navigation menu, single-column stacked grids, and full-width buttons.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/<your-username>/travel-destination-website.git

# Open the website
cd travel-destination-website
start index.html
```
